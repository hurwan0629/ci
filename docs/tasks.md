# 작업 목록

상태는 `할 일 → 진행 중 → 확인 필요 → 완료`로 관리합니다.
완료 전 관련 테스트와 전체 테스트, 린트·포맷·타입 검사 결과를 확인합니다.
새 아이디어는 먼저 브레인스토밍에 기록하고 범위를 합의한 뒤 작업으로 옮깁니다.

| 작업 | 상태 | 완료 조건 및 검증 |
|---|---|---|
| 프로젝트 뼈대 구성 | 완료 | 문서, src 패키지, 테스트, uv 환경, CI 구성. 로컬 pytest 1개, Ruff 린트·포맷, mypy 통과. |
| 1차 MVP 범위 합의 | 할 일 | 첫 플랫폼, 핵심 흐름, 포함·제외 기능, 완료 조건 합의. |
| 첫 사용자 흐름 작성 | 확인 필요 | [핵심 사용자 흐름](flows/core-flow.md) 초안 작성. 예외 상황과 완료 조건은 사용자 확인 대기. |
| Reddit 최신 게시글 수집 | 완료 | [수집 문서](flows/reddit-collection.md)의 함수와 단위 테스트 구현. 전체 pytest 21개, Ruff 린트·포맷, mypy 통과. 실제 Reddit 연동은 미검증. |
| HTML 시안 확인 | 할 일 | 합의한 흐름을 샘플 데이터로 확인하고 실제 기능과의 차이 표시. |

전체 MVP 범위는 논의 중이며, 개별 구현 작업은 사용자가 승인한 범위에서 진행합니다.
