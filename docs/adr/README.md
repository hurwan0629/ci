# 기술 결정 기록

DB, 외부 연동, 수집 실행 구조처럼 영향이 큰 결정을 확정할 때 기록합니다.
사소한 구현 선택이나 아직 검토 중인 아이디어는 별도 ADR을 만들지 않습니다.

파일 이름은 `0001-short-title.md`처럼 순서를 붙입니다.
각 기록에는 날짜, 상태, 배경, 검토한 대안, 결정, 이유와 영향을 적습니다.

초기 개발 환경은 uv와 Python 3.12, 검증 도구는 pytest·Ruff·mypy입니다.
패키지 설정과 버전은 저장소 루트의 `pyproject.toml`, `uv.lock`, `.python-version`에서 관리합니다.
