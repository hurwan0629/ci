# 문서 안내

## 제품과 작업

- [제품 개요](product/overview.md): 합의한 문제 정의와 제품 방향, MVP 미정 사항.
- [작업 목록](tasks.md): 상태, 완료 조건, 검증 결과.
- [브레인스토밍](brainstorm.md): 미확정 아이디어와 질문. 확정한 내용은 제품 문서에 반영합니다.

## 설계와 시안

- [사용자 흐름](flows/README.md): 사용자 행동, 정상 흐름, 예외 상황, 완료 조건.
- [기술 결정](adr/README.md): 중요한 결정과 이유.
- [데이터 불변 조건](db/invariants.md): 데이터가 항상 지켜야 하는 규칙.
- [HTML 시안](prototypes/README.md): 실제 구현 전 화면과 사용 흐름 확인.

설치 및 검증 명령은 [프로젝트 README](../README.md), 작업 규칙은 [AGENTS.md](../AGENTS.md)를 참고합니다.

## 문서 관리

- 아이디어와 확정된 요구사항을 구분합니다.
- 제품 동작을 바꾸면 관련 흐름과 테스트를 함께 갱신합니다.
- 큰 기술 결정을 확정할 때 ADR을 작성합니다.
- 같은 내용을 여러 문서에 복사하기보다 원본 문서로 연결합니다.
