# 핵심 사용자 흐름 (초안)

목적: 사용자가 지금 필요한 정보를 섹션별로 모아보고, 관련 글과 댓글의 출처를 확인합니다.
제품 방향을 구체화하기 위한 초안이며 MVP 범위를 확정하는 문서는 아닙니다.

## 시작 조건

사용자가 관심 상황이나 해결하려는 문제를 가지고 서비스에 들어옵니다.

## 정상 흐름

1. 사용자가 섹션을 만들고 현재 상황, 해결하려는 문제, 원하는 정보를 입력합니다.
2. 필요한 경우 AI와 대화해 수집 조건을 구체화합니다. AI의 개입 범위는 미정입니다.
3. 사용자가 조건을 확인하고 섹션을 저장합니다.
4. 서비스가 해당 조건에 맞는 게시글을 발견하면 섹션에 추가합니다.
5. 게시글에 추가 정보, 경험, 리스크 또는 반론을 보충하는 댓글이 있으면 연결해서 가져옵니다.
6. 사용자가 섹션을 열어 수집된 글과 관련 댓글을 확인하고 원문으로 이동합니다.

## 예외 상황 (제안)

- 조건이 부족한 경우: 부족한 내용을 안내하고 사용자가 보완합니다.
- 맞는 정보가 없는 경우: 수집 결과가 없음을 표시합니다.
- 수집이 실패한 경우: 기존 결과를 유지하고 실패 상태를 표시합니다.
- 관련 댓글이 없는 경우: 게시글만 표시합니다.

## 완료 조건 (제안)

- 저장한 섹션을 다시 열면 수집 조건을 확인할 수 있습니다.
- 발견한 게시글이 조건에 해당하는 섹션에 표시됩니다.
- 댓글은 관련 게시글과 연결되어 표시되고, 글과 댓글의 원문을 확인할 수 있습니다.
- 결과 없음과 수집 실패를 구분할 수 있습니다.

## 미정 사항

입력 필드, 첫 플랫폼, AI의 역할, 관련성 기준, 수집 주기, 중복 처리, 실패 후 재시도는 MVP 논의에서 정합니다.
