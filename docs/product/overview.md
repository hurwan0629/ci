# 제품 개요

## 해결하려는 문제

많은 계정을 팔로우하고 알림을 받아도 지금 하는 일에 맞는 정보를 찾기 어렵고, 불필요한 정보로 집중이 끊깁니다.

## 합의한 제품 방향

- 사용자는 서로 다른 목적을 가진 수집 섹션을 여러 개 만듭니다.
- 각 섹션에는 현재 상황, 해결하려는 문제, 원하는 정보 등 수집 조건을 설정합니다.
- 서비스는 조건에 맞는 정보를 발견하면 해당 섹션에 쌓아둡니다.
- 게시글과 관련된 추가 정보, 실제 경험, 리스크와 반론을 담은 댓글도 연결해서 가져옵니다.
- 사용자는 필요할 때 섹션을 열어 결과와 출처를 확인합니다.

## 검토 중인 흐름

상황 템플릿 입력 → AI와 수집 조건 구체화 → 사용자 확인 → 수집 → 관련 글과 댓글을 섹션에서 확인.
템플릿 항목과 AI의 역할은 아직 확정하지 않았습니다.

## MVP 범위

아직 확정하지 않았습니다. 아래 항목을 먼저 논의합니다.

- MVP에 포함할 플랫폼과 접근 방식. Reddit 최신 게시글 수집 함수와 단위 테스트부터 구현했으며, 실제 연동과 X 지원은 미정입니다.
- 섹션 생성 시 필요한 입력과 수집 조건.
- 게시글 및 댓글의 관련성 판단 기준.
- 수집 실행 방식과 주기, 중복 처리, 실패 시 동작.
- 결과 화면, 원문 연결, 사용자 피드백 방식.
- 사용자 및 인증 범위, 데이터 보관 범위.

## 개발 방식

- 사용 흐름과 완료 조건을 먼저 정하고 TDD로 구현합니다.
- HTML 시안으로 화면과 동작 흐름을 확인합니다.
- 세부 모듈은 실제 기능의 책임에 따라 나눕니다.
- DB는 프로젝트 지침에 따라 Docker 기반 PostgreSQL과 마이그레이션을 사용합니다.
- 웹 프레임워크, AI 제공자, 스케줄러, 별도 Worker와 작업 큐는 아직 정하지 않았습니다.
